## 📝 About the Game

TapTap is an engaging clicker game where you tap to accumulate points and unlock new features. Test your tapping speed and compete for high scores!

### Features
- 🖱️ Simple and intuitive tap mechanics
- 📊 Score tracking and statistics
- 🎯 Progressively challenging gameplay
- 🏆 Compete for the highest score
